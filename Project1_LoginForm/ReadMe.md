# C++ Authentication System
A simple **file-based authentication system** built using **C++ and Object-Oriented Programming (OOP)** concepts.

---

## Features
- ✅ User **Sign Up**
- ✅ User **Login**
- ✅ **Forgot Password** (Account verification only)
- ✅ Password **Hashing** (using `std::hash`)
- ✅ **Duplicate Username Validation**
- ✅ **Email Format Validation**
- ✅ File-based data storage
- ✅ Clean **OOP-based design**
Pro
---

## OOP Concepts Used
- **Encapsulation**  
  User data is kept private and accessed through class methods.

- **Abstraction**  
  Authentication logic is separated from the main function.

- **Single Responsibility Principle**  
  - `User` class → stores user information  
  - `AuthSystem` class → handles authentication logic

---

## Technologies Used
- **Language:** C++
- **Concepts:**  
  - Object-Oriented Programming (OOP)  
  - File Handling (`fstream`)  
  - Password Hashing (`std::hash`)  
  - Regular Expressions (`<regex>`)
